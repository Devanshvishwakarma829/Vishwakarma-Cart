# 🛒 Vishwakarma Cart

A modern, responsive e-commerce website built as a portfolio project using **HTML, CSS, and JavaScript**.

Vishwakarma Cart focuses on a clean shopping experience with a polished interface, product browsing, wishlist management, cart functionality, checkout flow, and responsive design.

---

## ✨ Features

* 🏠 Modern homepage with hero section
* 🔎 Product search
* 🏷️ Category filtering
* 🛍️ Featured products
* 📦 Dynamic product details
* 🛒 Add to Cart functionality
* 🔢 Product quantity management
* ⚡ Buy Now flow
* ❤️ Wishlist system
* ⭐ Product ratings and reviews
* 📋 Product highlights
* 💳 Checkout flow
* ✅ Order confirmation page
* 🧾 Dynamic cart totals
* 📱 Responsive design for mobile, tablet, and desktop
* 💎 Modern glass-style UI
* 🎨 Smooth hover and interaction effects
* 💾 Local browser storage for cart and wishlist data

---

## 🛠️ Tech Stack

* **HTML5** — Website structure
* **CSS3** — Styling, responsive layout, animations and UI
* **JavaScript** — Dynamic functionality and state management
* **LocalStorage** — Cart and wishlist persistence
* **Git & GitHub** — Version control

## 🚀 How to Run

1. Clone the repository.

```bash
git clone https://github.com/Devanshvishwakarma829/Vishwakarma-Cart
```

2. Open the project folder.

3. Open `index.html` in your browser.

Or use **VS Code + Live Server** for a better development experience.
